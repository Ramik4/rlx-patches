* **Voice-over translation (Yandex)**: plays a Yandex voice-over translation of the video, next to Morphe's own translation (YouTube)
* **Save to device**: built-in downloader for videos, audio, thumbnails and subtitles, with a library and an offline player with SponsorBlock (YouTube)
* **Quick download menu** for [YTindir](https://github.com/Ramik4/ytindir): qualities with codec and file size, audio (M4A, MP3) and the thumbnail (YouTube and YouTube Music)
* **RLX branding**: app icons, header logos, startup animation and app names, next to the original ones
* **RLX settings**: clearer sections, with *RLX Customizations* for the app name, icon, logo, font, theme colors, language and import / export
* **Recommended settings** from the first start, kept on updates and restorable with *Restore RLX default settings*
* **About page** with the RLX and Morphe versions, update check, release notes and credits
